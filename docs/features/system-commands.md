# System commands

Run Windows actions from Command mode (`>`). Type part of a name and press Enter.

## Commands

| Command | Effect |
| --- | --- |
| Lock | Locks the session. |
| Sleep | Sleeps the PC. |
| Hibernate | Hibernates. Shown only when hibernation is enabled in Windows. |
| Restart | Restarts the PC. |
| Shut down | Shuts the PC down. |
| Sign out | Signs out the current user. |
| Empty Recycle Bin | Empties the Recycle Bin. |
| Restart Explorer | Restarts the Windows shell (Explorer). |
| Wi-Fi on / Wi-Fi off | Turns the Wi-Fi adapter on or off. |
| Bluetooth on / Bluetooth off | Turns Bluetooth on or off. |

Fuzzy matching applies, so `slep` finds Sleep. See [search](search.md).

## Confirmation

Restart, Shut down, Sign out and Empty Recycle Bin need Enter twice.

## Sleep on Modern Standby laptops

Some laptops have no S3 sleep and use Modern Standby instead. On those, Sleep turns the display off, which is how Windows enters Modern Standby.

## When a command fails

The launcher stays open and shows the reason under the search box.
