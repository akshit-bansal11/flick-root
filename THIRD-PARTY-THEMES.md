# Third-party themes

Some of Flick's bundled themes are ports of editor colour themes. Flick takes a few colours from each upstream theme file (background, panel, text, muted text, accent, selection, line) and derives its own UI roles from them. Each upstream's licence and copyright are reproduced by reference in the table below: the licence file URL points to the full text and the copyright column carries the upstream's copyright line.

## Allowed licences

A theme is only ported when its licence is MIT or attribution-only:

- MIT
- ISC
- BSD-2-Clause
- BSD-3-Clause
- 0BSD
- CC0-1.0

Nothing that needs a request, a purchase, share-alike or copyleft terms is used: no Apache-2.0, GPL, CC-BY-SA, unlicensed or unclear licences.
