All notable changes to this project are documented here. Generated by git-cliff.
## [0.2.1] - 2026-10-20

### Added

- add/ shortcuts: one shortcut table for launcher and settings, checked against Windows and text-editing chords; Ctrl+Shift+C copy, Delete ends a process, Ctrl+1-4 modes, Ctrl+, settings, F1 shortcut sheet
- add/ motion: motion tokens with reduced-motion off switch; gliding selection, row fade-in, chip pop, press feedback, Copied status, settings nav glide and page fade
- add/ tour: interactive animated tour on the real launcher UI with sample data, show-me typing, step checks, live theme preview; global hotkeys paused while it runs
- add/ welcome: first-launch welcome screen with animated logo asks to take the tour; Not now points to Settings; Take the tour in Settings > General; hotkeys resume when Settings closes

### Fixes

- fix/ scan: drive roots marked hidden or system (C:, D:) are walked; only their children are filtered
- fix/ launcher: real acrylic blur via DWM backdrop with the frame extended; window grows with its content again; no focus ring on the input
- fix/ live test: no Windows caption buttons on the glass panel; scans run one after another; programs skip dot-folders and loose fuzzy hits; Welcome step advances on first mode; action labels per row; thin scrollbar
- fix/ launcher: a window subclass keeps caption and min/max/close styles off, so Windows draws no buttons on the glass panel
- fix/ review: hotkey capture no longer closes Settings; rows readable on first frame; browser chords blocked in launcher and tour (tour uses PageDown/PageUp); Copied only after a real copy via Rust; Delete edits text unless a process row is armed

### Removed

- rem/ launcher: tutorial removed from the launcher; it moves to the welcome window

### Updates

- up/ docs: v0.2.1 keys from the shortcut table, welcome screen and tour, programs matching, command reference
## [0.2.0] - 2026-10-19

### Added

- add/ index-files: programs scan finds exe, msi, apk and other launchable files on every drive
- add/ search: programs from every drive in app search, below Start-menu apps; search scope for apps-only and commands-only
- add/ programs: appinstaller, macOS app/pkg/dmg and Linux AppImage/deb/rpm/flatpak/snap/run/sh types; .app bundles kept whole
- add/ query: thinking modes, one per enabled provider and model; the chosen one answers first, then the usual fallback
- add/ launcher: Tab and Shift+Tab switch thinking mode (provider and model) in ask mode; extra models per provider in Settings
- add/ appearance: six themes (Glass, Frost, Midnight, Aurora, Ember, Solid), glass strength and scheme in Settings > Appearance, applied to the launcher on every show
- add/ tutorial: skippable step-by-step tour in the launcher with try-it examples; Esc skips, F1 replays, Replay button in Settings

### Fixes

- fix/ icons: shell icons only for Start-menu apps and local .exe files, so a scanned .url or .lnk cannot pull an icon from a network share
- fix/ review: frecency ranks apps under !; programs match in their own index off the keystroke thread (cap 50k, benched); no Start-menu duplicates; admin on Desktop shortcuts; stable program ids; programs scan stops when switched off
- fix/ review: programs toggle in Settings; glass slider saves on release; hint rows are a listbox; pasted prefixes; tutorial keeps its step and Alt+T tries the example; panel fits short screens
- fix/ window: layout test expects the work-area margin; v0.2.0 bench numbers

### Updates

- up/ docs: v0.1.0 bench numbers from the GitHub runner
- up/ launcher: prefix-only modes (> commands, ! apps, / find, ? ask) with a mode chip; plain text shows the prefix hints; no tab switcher
- up/ launcher: liquid glass panel window with acrylic, rounded corners and height that follows the results; opaque when Windows transparency is off
- up/ docs: v0.2.0 prefixes, programs scan, thinking modes, glass themes and tutorial; ADR-001 panel window; command reference; site features
- up/ release: v0.2.0
## [0.1.0] - 2026-10-19

### Added

- add/ benches: query() benches for nlfind, ports, media, explain and capture; bench.yml runs every bench on GitHub
- add/ docs: pages for the five v0.1.0 features, Spotify app setup, decision engines; ADRs updated for v0.1.0 and the new launcher placement

### Features

- feat/ find: index every fixed non-system drive by default, with system folders skipped
- feat/ shell: launcher window spans the monitor under the cursor with an acrylic blur and no per-keystroke resizing
- feat/ launcher: centred 40%-wide bar over a tinted full-screen backdrop; click outside closes; no window resizing
- feat/ launcher: redesign the bar after the Design Lab — floating panel, search glyph, hint switcher, accent selection, kbd chips
- feat/ settings: Index all drives toggle that rescans immediately; hide the backdrop from assistive tech
- feat/ launcher: no backdrop, panel centred with a stable input, Design Lab look — match highlighting, group labels, subtitles, footer, empty state
- feat/ apps: find per-user and desktop-only apps (Spotify) from Uninstall registry entries and Desktop shortcuts; launch them by path
- feat/ decision: offline natural-language parser (stage 1) — filler removal, known-folder roots, type words to extensions, date filters; 50-phrase table test
- feat/ decision: /v1/systemone client for Laya, Kev and Jev and a strict-JSON LLM picker; auto-open only allowlisted document/media types
- feat/ win: media session now-playing and transport controls (GSMTC); TCP/UDP port owners and guarded process kill
- feat/ win: selected text via UI Automation with a Ctrl+C fallback that restores the clipboard
- feat/ settings: Decision engine page — parser always on, Laya/Kev/your AI/Jev off by default, probe status, host-bound keys
- feat/ settings: Integrations page — Spotify app setup, YouTube key, Obsidian, Markdown, Notion and webhooks, every secret write-only and host-bound
- feat/ nlfind: plain-language Find — offline parser, filters by folder/type/date, auto-open only clear document/media winners, optional decision engines on names and folders only
- feat/ ports: "port 3000" and "proc <name>" list processes with memory, uptime and command line; Backspace then Enter ends one
- feat/ media: play, pause, next, previous and now playing on any player; "play X on spotify|youtube" opens a search
- feat/ media: optional Spotify connection with your own app (PKCE on 127.0.0.1) — play, queue, like, devices, playlists; YouTube key opens the first result
- feat/ explain: second hotkey captures the selected text, shows it before sending, and blocks secret-looking text
- feat/ capture: "log 250 lunch" to an Obsidian daily note, a Markdown file, Notion or a webhook — parsed offline, secrets blocked, per-target Test
- feat/ web: landing page shows the three modes and all ten features with examples and docs links

### Fixes

- fix/ ci: write SHA256SUMS.txt with LF endings so sha256sum -c works
- fix/ find: scan drives on 2 background-priority threads so startup no longer pins every core; log scan time and slow searches
- fix/ settings: one scrollbar; restyle pages after the Design Lab settings window — accent-bar nav, per-item cards, icon tiles, status text, two button tiers
- fix/ win: bound clipboard reads by the block size; keep Flick's clipboard restores out of history and cloud sync
- fix/ capture: refuse Obsidian daily notes or folders that resolve outside the vault through links, checked before anything is created
- fix/ ci: run only bench targets in bench.yml so libtest doesn't reject --noplot
- fix/ review: Explain never sends Ctrl+C to terminals or editors with terminals; relative-date phrases skip the NL cache; Custom decision engine; plain-http engines refused; Spotify disconnects on revoked tokens; keys deleted only after config saves
- fix/ benches: lib targets opt out of cargo bench so criterion flags reach only criterion

### Updates

- up/ ci: build installers only on GitHub — manual test builds upload an artifact, and release.ps1 checks CI instead of running the gate locally
- up/ docs: BSD commands, engines, timeouts and Explain limits match the code; README status
- up/ release: v0.1.0
