# Project rules

**Session start:** if .agent/HANDOFF.md exists, read it first and resume from its Next section (KICKOFF.md section 10). Keep it current after every commit. Decide for yourself; do not ask questions or wait for approval (KICKOFF.md section 9).

Free, open-source, keyboard-first Windows launcher: Command, Find and Query modes in one bar. Tauri 2 shell, Rust crates for all logic, React 19 + TypeScript UI, Next.js site in apps/web. KICKOFF.md is the spec; docs/adr/ holds the locked decisions.

## FOSS-first

- Flick is a wrapper: no bundled models or keys, nothing AI-related on by default. The user picks every provider and engine. No feature may require a paid account.
- Every feature is a module behind the Feature trait with a toggle. Off means stopped: no tasks, watchers, timers or network clients left running.

## Commands

- Desktop dev: `pnpm --filter desktop tauri dev`
- Rust: `cargo check -p <crate>`, `cargo test -p <crate>`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`
- Benches: `cargo bench -p launcher-core`, `cargo bench -p index-files`
- UI: `pnpm --filter desktop typecheck`, `pnpm --filter desktop test`, `pnpm lint`
- Web: `pnpm --filter web dev`, `pnpm --filter web build`
- Release: `pwsh -File scripts/release.ps1 <version>`

## Rust

- Libraries use `thiserror` error enums. `anyhow` only in apps/desktop/src-tauri.
- No `unwrap()` or `expect()` outside tests. Errors carry context.
- `unsafe` only in crates/index-apps and crates/win, each block with a `// SAFETY:` comment stating the invariant.
- No blocking calls inside async code; use `spawn_blocking` for COM, disk scans and SQLite.
- Public items have doc comments. Clippy is clean with `-D warnings`.
- The brand name lives only in crates/launcher-core/src/brand.rs.

## TypeScript and UI

- Strict mode, no `any`, Biome formatting and lint clean, `tsc --noEmit` clean.
- One file, one purpose. Feature folders (launcher/, settings/, query/), not type folders.
- Colors, radius, row height and fonts only through the tokens in tokens.css. No literal colors in components.
- No business logic in components. Keyboard state is a pure reducer with tests.
- The brand name lives only in src/brand.ts.

## Performance budgets

Hotkey to visible p95 <= 50 ms. Command match <= 2 ms for 2,000 apps. Each feature's query() <= 0.5 ms. Find match p95 <= 25 ms over 300k paths. Launch call <= 30 ms. Idle RAM <= 120 MB. A change that breaks a budget is a bug.

## Privacy and security

- Secrets follow ADR-011 in KICKOFF.md: Windows Credential Manager only, write-only from the UI (no command returns a secret), SecretString in memory, bound to one HTTPS host, redacted from logs and panics. Never in config, SQLite, fixtures or snapshots.
- The WebView makes no network calls; Rust does. Keep the CSP and Tauri capabilities minimal. Model output is untrusted and can never trigger an action.
- Decision engines (Laya, Kev, Jev, the LLM picker) receive file names and parent folders only, never file contents, never keys.
- Explain this shows the captured text before sending and blocks text that looks like a secret.
- No telemetry. No network calls on the keystroke path.

## Git

- Follow the commit conventions in ~/.claude/CLAUDE.md (prefixes feat/, fix/, up/, rem/, sm/, add/, add-p/, hide/, init/).
- One commit per task card. Only the controller commits. Never force-push.
- CHANGELOG.md is generated by git-cliff; do not edit it by hand.

## Agents working in this repo

- Edit only the files your task card owns. Need a change elsewhere: stop and report it under NEEDS.
- Run only fast checks for your own package. Heavy builds belong to the tester, one at a time.
- Before using an external API, fetch its current docs instead of relying on memory.
